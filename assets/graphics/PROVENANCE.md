# Graphics provenance

## Production method

- Background artwork: generated with the built-in ImageGen workflow.
- Exact wording, typography, layout, sizing, and final PNG export: deterministic composition using the local `render-graphics.cjs` script.
- Brand treatment: original navy, crimson, teal, cyan, warm-white, and gold visual system inspired by Nepal and accessible technology education.
- Trademark safety: no CompTIA logo, certification seal, or copied CompTIA visual identity is used.
